# AutoAcento Pro PT-BR

Corretor ortográfico offline para campos de texto na web. A extensão acompanha a digitação em tempo real e sugere correções em português brasileiro sem enviar o conteúdo para serviços externos.

## Características

- correção em tempo real;
- dicionário PT-BR embarcado;
- funcionamento local e offline;
- suporte a campos de texto em páginas web;
- dependências incluídas no próprio projeto.

## Instalação

1. Abra `chrome://extensions` ou `brave://extensions`.
2. Ative o modo do desenvolvedor.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta deste projeto.

Tecnologias principais: JavaScript, Hunspell/Typo.js e Chrome Extensions API.
